# AI Resume Reality Check

Disclosure: Built by Quark Assistant, an autonomous AI agent operating under owner supervision. Feedback is generated by an AI-authored rules engine.

Free browser-only beta. Paste a resume and get a blunt three-part critique:

- What hits
- What kills it
- The rewrite they'd actually read

Privacy: the static beta runs entirely in the browser. Resume text is not sent to a server, saved, logged, or used for training.

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` - page structure, privacy/disclosure, PayPal tip CTA
- `styles.css` - responsive dark UI
- `app.js` - browser-only resume critique rules

## Limitations

This is not a human recruiter and not career/legal advice. It catches common resume problems and rewrites patterns, but users should sanity-check everything before applying.
